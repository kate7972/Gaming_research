# Gaming_research
# Анализ игровой индустрии (2000–2013)  Проект по подготовке данных для исследовательской статьи

Проект для подготовки развлекательно-познавательной статьи для IT-ресурса об истории развития видеоигр в XXI веке.  
Цель проекта — привлечь новую аудиторию в игру *«Секреты Темнолесья»* через качественное исследование эволюции игровой индустрии с 2000 по 2013 год.

В проекте выполняется полная предобработка данных, фильтрация и подготовка «чистого» датасета для написания статьи, а также выделяются ключевые платформы-лидеры по количеству выпущенных игр.

## Задачи проекта

1. Изучить собранные данные о продажах и оценках игр.
2. Проверить корректность данных и выполнить полную предобработку (очистка от пропусков, дубликатов, выбросов).
3. Отфильтровать данные за нужный временной период (2000–2013 гг.).
4. Выделить ТОП-7 платформ-лидеров по количеству выпущенных игр за указанный период.
5. Подготовить итоговый датасет для написания статьи.

## Описание данных

Файл с данными содержит информацию о продажах игр разных жанров и платформ, а также пользовательские и экспертные оценки.

| Поле | Описание |
|------|-----------|
| Name | Название игры |
| Platform | Название платформы (PS4, Xbox One, PC и др.) |
| Year of Release | Год выпуска игры |
| Genre | Жанр игры (Action, Sports, RPG и т.д.) |
| NA_sales | Продажи в Северной Америке (млн копий) |
| EU_sales | Продажи в Европе (млн копий) |
| JP_sales | Продажи в Японии (млн копий) |
| Other_sales | Продажи в остальном мире (млн копий) |
| Critic_Score | Оценка критиков (от 0 до 100) |
| User_Score | Оценка пользователей (от 0 до 10) |
| Rating | Рейтинг ESRB (возрастная категория) |

> ESRB (Entertainment Software Rating Board) — ассоциация, определяющая рейтинг компьютерных игр и присваивающая им возрастную категорию.

## Используемые инструменты

- Python (pandas, numpy) — обработка и анализ данных
- Matplotlib / Seaborn — визуализация
- Jupyter Notebook — интерактивная среда разработки

## Результаты работы

- Очищенный и структурированный датасет за 2000–2013 гг.
- ТОП-7 платформ по количеству релизов (с графиками и таблицами)
- Готовые данные для написания статьи об истории игр
